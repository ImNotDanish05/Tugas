## ✨ Deskripsi

Repository ini dibuat sebagai tempat menyimpan berbagai tugas-tugas kecil atau acak yang diberikan selama perkuliahan maupun eksperimen pribadi. Tidak semua tugas membutuhkan struktur repo yang kompleks, jadi semua dikumpulkan di sini sebagai catatan digital dan dokumentasi ringan.

## 📚 Isi Repo

Beberapa jenis tugas yang mungkin ada di repo ini:
- Tugas kelas yang tidak butuh struktur besar
- Catatan coding iseng
- Latihan syntax dasar
- Coba-coba modul atau library
- Mini projek kilat
